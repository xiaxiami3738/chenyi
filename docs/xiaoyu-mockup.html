去接入 API →

对话会消耗你自己的模型额度；额度用尽时她会暂时说不上话。

切换方式：把 #xiaoyu-card 的 data-state 在 locked / ready 之间改；ready 显示输入行、locked 显示虚线提示框，两者互斥。徽章文案由 JS 写入。
